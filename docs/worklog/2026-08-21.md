## 关键决定

- `sortOrder` 在 `queryS3Layer` / `queryCampusLayer` 的 Zod schema 用 `.optional()`（不加 `.default()`），因为这两个函数被内部的 plain-object caller（handler.ts、findBuildingsByYear.ts 等）直接调用，不经过 `.parse()`；加 `.default()` 后 `z.infer` 输出类型变 required，导致所有调用点 TS 报错
- `queryBuildingAttributes` 保留 `.default('desc')` 因为它只经过 `QueryBuildingAttributesInputSchema.parse(rawInput)` 调用
- 不创建 shared utils 文件，每个工具内联 null-last sort helper，保持工具自包含
