## Key Decisions

- **Two API Gateways, not two Lambda aliases with different env vars**: Lambda aliases freeze environment variables at publish time, making per-alias env-var differences impossible to maintain cleanly. Two separate APIs with different authorizers is cleaner and matches the HTTP API v2 model.
- **OAC over OAI**: Origin Access Control (OAC) is the current AWS recommendation for S3-to-CloudFront; OAI is legacy. OAC uses IAM-based bucket policies rather than a special CloudFront identity.
- **CloudFront 403 → index.html**: Single-page apps need this; a 403 from S3 (file not found) is rewritten to 200/index.html so client-side routing works.
