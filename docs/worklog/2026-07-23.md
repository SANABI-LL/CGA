### 建筑背景层最终修复：MultiPolygon → Polygon 展平

**问题**：buildings.geojson 几何类型为 `MultiPolygon`。MapLibre GeoJSON worker 无法正确 tile 化——层存在、paint 正确、source 有 308 个 feature，但 `querySourceFeatures` 始终返回 0，视觉不渲染。

**诊断过程**：
1. 确认 `stripZ()` 已生效（坐标为纯 2D）
2. 手写测试 `Polygon` 矩形 → 正常渲染，querySourceFeatures=2
3. 将 `MultiPolygon` 展平为独立 `Polygon` feature → querySourceFeatures=219 → 正常渲染

**修复**（`inject-backend.js` 的 `stripZ()`）：
```javascript
if (f.geometry.type === 'MultiPolygon') {
  return f.geometry.coordinates.map(polyCoords => ({
    type: 'Feature', properties: f.properties,
    geometry: { type: 'Polygon', coordinates: strip2D(polyCoords) }
  }));
}
```

**验证**："show me trees near Levi Hall" → 176 个建筑 feature 渲染，截图可见棕褐色建筑轮廓覆盖在树点位之下。

### 建筑年份渐变色

**需求**：AI 返回建筑查询结果（如 "show me a gradient color map that reflects building's age"）时，`bldg-hit-fill` 用 `Year_Completed` 字段渐变着色而非固定 maroon。

**实现**（`scripts/build-with-backend.mjs` patch 12）：

MapLibre data-driven `case`+`interpolate` 表达式替换 `T.maroon`：
- `Year_Completed` 有效（非 null/0）→ 线性插值 1890→深蓝→1960→绿→2020→红
- 无年份数据 → fallback `#888888`（中性灰）
- `fill-opacity` 从 0.34 提升至 0.72（色彩可见性更好）

色标：`#2166ac`(1890) → `#74add1`(1930) → `#a6d96a`(1960) → `#fdae61`(1990) → `#d73027`(2020)
