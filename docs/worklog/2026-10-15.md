## 关键决定

- **只渲染选中楼层**：MapLibre `fill-extrusion` 各 source 独立合成深度，多楼层同时存在会互相遮挡，与规格一致。
- **插入位置固定在外层 `</head>` 前**：bundler 在 `DOMContentLoaded` 里做 `replaceWith()`，内层 template 里的脚本会被丢弃；外层 `<head>` 脚本挂在 `document` 上永久有效（见 CLAUDE.md Bundle 注入规则）。
- **amber 选中轮廓不做共边去重**：规格要求形成闭合环，与内部 wall 的去重逻辑区分开。

## 关键决定（续）

- **附件内存不落盘**：SIMS 导出含 PIN 和法律描述，属内部数据；规格明确禁止写 S3/日志。
- **Census Geocoder 而非 Google/Mapbox**：无需 API key，公开可用；结果缓存 S3 避免重复调用，Lambda 冷启动不付费。
- **范围地址解析（"1160-74 E 55th"）**：取起始号前缀拼接片段 `hi = parseInt("11" + "74")`，覆盖 SIMS 地址写法；不依赖外部解析库。
- **`_modelSummary.summary` 报附件行数**：地图只显示有底图的楼栋，但用户关心的是文件里有多少条，防止模型混淆"45 properties / 38 mapped"。
