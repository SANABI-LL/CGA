## Key Decisions

- **Render selected floor only**: MapLibre `fill-extrusion` composes depth independently per source; multiple floors present simultaneously would occlude each other. This matches the spec.
- **Inject at outer `</head>`**: The bundler runs `replaceWith()` inside `DOMContentLoaded`; scripts inside the inner template are discarded. Scripts in the outer `<head>` attach to `document` and remain valid permanently (see CLAUDE.md Bundle Injection Rules).
- **Amber selected-room outline does not deduplicate shared edges**: The spec requires a closed ring, distinct from the wall deduplication logic.

## Key Decisions (continued)

- **Attachment data never persisted to disk**: SIMS exports contain PINs and legal descriptions — internal data; spec explicitly forbids writing to S3 or logs.
- **Census Geocoder over Google/Mapbox**: No API key required; publicly available; results cached to S3 to avoid repeated calls and Lambda cold-start costs.
- **Range address parsing ("1160-74 E 55th")**: Takes the leading digits of the start number and appends the suffix of the end number (`hi = parseInt("11" + "74")`); covers SIMS address formatting without an external parsing library.
- **`_modelSummary.summary` reports attachment row count**: The map only shows buildings with matching footprints, but users care about how many records are in the file — prevents the model from conflating "45 properties / 38 mapped".
