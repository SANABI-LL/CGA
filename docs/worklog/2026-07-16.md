### 功能 1：AI 文字摘要 + 地图可视化共存

- 修复 `sc.legend` 缺失导致的 `Cannot read properties of undefined (reading 'map')` 崩溃：补全 `legend` 数组和 `legendSquare` 字段。

### 功能 2：Keller Center 位置修正
**问题**：`CAMPUS_LOCATIONS` 中 `keller center` 坐标指向 53rd St 附近（Polsky Exchange North），树木查询返回 0 棵。  
**修复**：查阅 S3 `buildings.geojson`，定位 `DISCRIPT1: "Keller Center"` / `ADDRESS: "1307 EAST 60TH STREET"` → `{lat: 41.7856, lng: -87.5940}`，部署 Lambda 验证返回 60th St 区域树木。  
文件：`backend/lambdas/ai-agent/tools/campus/findCampusNearby.ts`，同时修正多个建筑坐标。

### 功能 3：Trees popup 字段修复（本次主要工作）
**问题**：鼠标悬停树点时 popup 显示"undefined"，因 bundle 内 popup 模板用的是 `genTrees()` 伪造字段（`p.species`, `p.year_planted`, `p.dbh_in`, `p.condition`），S3 真实数据无这些字段。  
**修复**：在 `scripts/build-with-backend.mjs` 新增 patch 8，从 `html` 字符串直接提取 OLD popup 模板，用 `.replace()` 替换为真实字段：
- `p.species` → `p.CommonName || p.Common_Nam || 'Unknown'`
- `Planted ... DBH ... condition` → `p.Condition || p.conditionC || '—' · canopy p.CanRadius ft radius`

**踩坑**：第一版用 `'\\' radius'`（foot 符号），写入 HTML JSON 模板后变成非法 `\'` 转义，触发 "Bad escaped character in JSON at position 126150"。改为 `'ft radius'` 解决。  
构建输出：16 patches 全通过，3628770 bytes，"✓ trees popup 字段修复 (2 处)"。

### 验证
- "where are all linden trees" → 文字摘要正确（541 棵，种类/年龄/状况分类表）
- "Map results" 按钮出现，点击后切换到 composing 地图视图（541 features 显示）
- 构建产物 grep 确认：`CommonName || p.Common_Nam || 'Unknown'` 和 `Condition || p.conditionC || '—'} · canopy ${p.CanRadius ? p.CanRadius + 'ft radius'` 均已写入两处 popup 模板
